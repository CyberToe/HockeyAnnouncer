# 🏒 Hockey Goal Announcer

A web-based application for announcing hockey goals with natural voice synthesis. Perfect for live hockey games, tournaments, or practice sessions.

## Features

- **Team Management**: Create and manage two hockey teams with custom names and colors
- **Player Roster**: Add players with names and jersey numbers
- **Goal Recording**: Record goals with scorer, assists, period, and time
- **Voice Announcements**: Natural text-to-speech announcements for each goal
- **Goal Log**: Complete history of all recorded goals with playback
- **Data Persistence**: Save and load game data using browser local storage
- **Mobile Friendly**: Responsive design that works on desktop and mobile devices

## Usage

1. Open `index.html` in any modern web browser
2. Set up your teams by adding player names and numbers
3. Record goals using the form - select team, scorer, assists, period, and time
4. Listen to natural voice announcements as goals are recorded
5. Manage your game data with save/load functionality

## Voice Announcements

The app generates announcements like:
> "Goal! by number 19, Sarah Johnson, assisted by number 9, Emily Carter, in the second period with 4:25 remaining."

## Technical Details

- **Platform**: Web application (HTML, CSS, JavaScript)
- **Speech Engine**: Browser Web Speech API
- **Storage**: Browser Local Storage
- **Offline**: Works without internet connection
- **No Backend**: Pure client-side application

## Browser Compatibility

- Chrome/Chromium (recommended)
- Firefox
- Safari
- Edge

## Setup

1. Clone this repository
2. Open `index.html` in your web browser
3. Start announcing goals!
